# FaceHarmony AI ✨

Нейросетевое веб-приложение для анализа морфологического сходства, фенотипической гармонии и совместимости лиц на базе **Google Gemini API** (`gemini-3.5-flash-lite`, `gemini-3.5-flash`, `gemini-3.8-flash`).

---

## 🚀 Возможности

- **Морфометрический анализ:** Оценка геометрии овала лица, пропорций черт (глаза, нос, губы, скулы), мимического резонанса и фенотипического типажа.
- **Откалиброванная шкала гармонии (15% — 98%):**
  - `15–39%` — Выраженный визуальный диссонанс / Несовместимость типажей
  - `40–59%` — Контрастный дуализм / Умеренное сходство
  - `60–74%` — Органичный баланс противоположностей
  - `75–88%` — Высокая фенотипическая гармония
  - `89–98%` — Зеркальное фенотипическое сходство
- **Темный футуристичный UI:** Glassmorphism, Tailwind CSS, динамический радиальный прогресс-бар, шкалы подметрик, списки схожих и комплементарных черт.
- **Демо-режимы в 1 клик:** Мгновенное переключение между гармоничной и контрастной парой для наглядной проверки.

---

## 🛠️ Стек технологий

- **Backend:** Node.js, Express 5, CORS, Dotenv, `@google/genai`
- **Frontend:** HTML5, Tailwind CSS, Lucide Icons, Canvas API
- **Deployment:** Docker, Docker Compose, PM2, Nginx

## 📦 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/drukplus/face-harmony.git
cd face-harmony
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env`:
```env
PORT=3000
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Запуск сервера
```bash
npm start
```
Откройте в браузере: `http://localhost:3000`
