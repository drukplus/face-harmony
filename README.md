# FaceHarmony AI ✨

Нейромережевий вебзастосунок для аналізу морфологічної схожості, фенотипічної гармонії та сумісності облич на базі **Google Gemini API** (`gemini-3.5-flash-lite`, `gemini-3.5-flash`, `gemini-3.8-flash`).

---

## 🚀 Можливості

- **Морфометричний аналіз:** Оцінка геометрії овалу обличчя, пропорцій рис (очі, ніс, губи, вилиці), мімічного резонансу та фенотипічного типажу.
- **Відкалібрована шкала гармонії (15% — 98%):**
  - `15–39%` — Виражений візуальний дисонанс / Несумісність типажів
  - `40–59%` — Контрастний дуалізм / Помірне сходження
  - `60–74%` — Органічний баланс протилежностей
  - `75–88%` — Висока фенотипічна гармонія
  - `89–98%` — Дзеркальна фенотипічна схожість
- **Темний футуристичний UI:** Glassmorphism, Tailwind CSS, динамічний радіальний прогрес-бар, шкали підметрик, списки спільних та взаємодоповнюючих рис.
- **Демо-режими в 1 клік:** Миттєве перемикання між гармонійною та контрастною парою для наочної перевірки.

---

## 🛠️ Стек технологій

- **Backend:** Node.js, Express 5, CORS, Dotenv, `@google/genai`
- **Frontend:** HTML5, Tailwind CSS, Lucide Icons, Canvas API
- **Deployment:** Docker, Docker Compose, PM2, Nginx

## 📦 Швидкий старт

### 1. Клонування репозиторію
```bash
git clone https://github.com/drukplus/face-harmony.git
cd face-harmony
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Налаштування змінних оточення
Створіть файл `.env`:
```env
PORT=3000
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Запуск сервера
```bash
npm start
```
Відкрийте у браузері: `http://localhost:3000`
